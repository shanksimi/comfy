# my-comfy-nodes

Tập hợp custom nodes cá nhân dùng cho ComfyUI.

## Nodes bao gồm

| Node | Mô tả |
|------|-------|
| `Save Image Plus (Custom)` | Lưu ảnh với tên file tùy chỉnh |

## Cài đặt

### Qua ComfyUI Manager (Khuyên dùng)

Tìm `my-comfy-nodes` trong danh sách Install Custom Nodes của Manager, sau đó nhấn Install.

### Thủ công

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/USERNAME/my-comfy-nodes.git
cd my-comfy-nodes
pip install -r requirements.txt
```

## Yêu cầu

- ComfyUI đã cài đặt
- Các thư viện trong `requirements.txt` (nếu có)
